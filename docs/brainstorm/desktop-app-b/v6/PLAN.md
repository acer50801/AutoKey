# 按鍵輔助 B 整合版｜設定檢查與詞綴篩選

版本：v6｜待確認設計

首頁優先顯示按鍵、座標與偵測點缺漏。裝備製作先設定詞綴，再設定改造石，並支援交易站式搜尋和多群組。

本人核准以對話為準；本文件沒有自動批准或開始開發功能。

v6 為這三項改動的成品設計草案。畫面與資料均為靜態示例，開發計畫在設計確認後拆解。

## 成品目標

打開首頁就知道哪個功能需要補設定。在裝備製作輸入詞綴關鍵字，選定候選後用上下限和群組表達達標條件。

使用者：使用 PoE 1 國際服繁體中文介面的按鍵輔助使用者。

## 使用流程

1. 首頁檢查設定：先看紅框缺漏。傳送卷軸缺 X、Y，藥劑 2 尚未指定偵測點。補完後回到首頁，該項變成綠框。只需按鍵的滑鼠連點依其按鍵設定判斷。
2. 用關鍵字加入詞綴：在改造石洗詞綴上方新增群組和條件，輸入「火焰」，選「\+\#% 火焰抗性（顯性）」，再輸入最小 30、最大 45。若只在意下限，可留空最大值。
3. 組合多群組：用必須命中指定火抗，排除最大魔力，以至少命中 N 條接受生命或能量護盾，再用加權總和衡量火抗和生命。製作以群組結果判斷是否達標。

## 已確認範圍

- R16 首頁按設定狀態顯示紅框與綠框：首頁優先顯示各功能的按鍵、座標與偵測點是否設定齊全。缺必要設定顯示紅框，已設定好顯示綠框。
- R17 詞綴規則移到改造石洗詞綴上方：裝備製作頁先顯示「詞綴條件與比對規則」，接著顯示「改造石洗詞綴」。
- R18 詞綴模糊搜尋、選取與上下限：以 PoEDB 繁中 PoE 1 詞綴建立搜尋目錄。輸入部分文字即可選出詞綴。可比較的數值分別有最小值及最大值。
- R19 交易站式多群組：同一份製作條件可加入多個群組，包含必須命中、排除、至少命中 N 條、加權總和。

## AI 建議，尚未採用

- P16 缺漏優先與定位入口：紅框置前並列出欄位或點位名稱。點卡片可開啟對應設定。依目前模式檢查必填依賴。已停用、暫停或遊戲未連線分開標示，避免和設定完整度混在一起。
- P17 PoEDB 本機詞綴索引：以 PoEDB 詞綴索引、All 和相關分類頁盤點覆蓋，記錄來源及資料版本。相同詞義的不同階級合成一個候選，保留可區分的來源與原始階級。用本機資料查詢，資料更新失敗時可繼續用上一個已驗證版本。
- P18 區分能搜尋與能比對：候選附顯性、固定等來源標籤。只在已確認能從繁中物品文字辨識時啟用數值條件。多數值詞綴須標明比對欄位，無數值詞綴可做有無判斷。可辨識但不會被目前方式重擲的詞綴加註來源或適用性。
- P19 群組合併與數值判定：所有啟用群組皆通過才達標。上下限含邊界，兩欄皆空時檢查是否存在，最小值大於最大值時提示。排除群組中任一條符合就淘汰。至少命中以條件計數，每條最多算一次。加權群組按詞綴值乘權重後加總，與群組上下限比較。已確定缺少的詞綴計 0，讀取或數值辨識失敗則顯示無法判定。
- P20 保留既有條件的語意：以同一份規則供改造、混沌與重鑄＋點金引用。對應明確的舊條件可轉成群組，詞綴名／階級及無法安全轉換的條件須保留原文供核對。

## 驗收條件

- A16\-1 → R16：操作「留空傳送卷軸的 Y，只設定 X 與觸發鍵，再補上有效 Y。」；預期「首頁先顯示紅框及缺少 Y，補齊必填設定後轉綠。」。
- A16\-2 → R16：操作「藥劑槽有輸出鍵，但引用的偵測點被刪除或缺必要顏色。另有只需按鍵的功能已完成綁定。」；預期「藥劑槽顯示紅框及具體原因。只需按鍵的功能保持綠框。」。
- A17 → R17：操作「打開裝備製作頁，從製作控制向下查看。」；預期「詞綴條件與比對規則位在改造石洗詞綴正上方。」。
- A18\-1 → R18：操作「輸入「火焰」，在候選中選顯性的 \+\#% 火焰抗性。」；預期「清單顯示火焰抗性及其他火焰相關詞綴。選取後呈現可編輯的最小值與最大值。」。
- A18\-2 → R18：操作「對同一條詞綴分別測最小值 30、最大值 45，以及 30 至 45。」；預期「只填最小值時 29 不符、30 通過。只填最大值時 45 通過、46 不符。兩欄都填時僅 30 至 45 通過。」。
- A18\-3 → R18：操作「對照 PoEDB 的 All 和相關分類索引抽查一般詞綴、工藝和固定詞綴，並檢查來源覆蓋清單。」；預期「資料匯入逐類列出納入數和例外。相同詞義的階級集中呈現，不同來源仍能區分。缺少來源、無法解析或無法比對的項目可查明原因。」。
- A19\-1 → R19：操作「建立必須火抗、排除最大魔力、生命或能量護盾至少一條、加權至少 70 分的群組。用火抗 35%、最大生命 80、無最大魔力的物品文字測試。」；預期「四組均通過。若增加一條符合排除條件的最大魔力，整體改為不達標。」。
- A19\-2 → R19：操作「設定火抗權重 1、最大生命權重 0\.5，先將群組門檻設為 70，再提高到 76。」；預期「火抗 35、最大生命 80 的加權總和為 75，先通過，再變為不通過。」。

- [confirmed] 紅綠框與首頁優先順序：按鍵、座標與偵測點是否設定完成是首頁主要資訊。（本輪第 1 項。）
- [confirmed] 選詞綴及填數值：採交易站式搜尋選單與獨立最小值／最大值，詞綴規則移至改造石上方。（本輪第 2、3 項。）
- [confirmed] 條件組合方式：採交易站式多群組，包含必須命中、排除、至少命中 N 條及加權總和。（本輪選擇「加入交易站式多群組」。）
- [proposed] 設定完成的判定：每個功能依本次模式檢查必需的按鍵、座標、引用點及必要顏色。失效的校準或空值要顯示缺漏。已設定只代表設定齊全，執行狀態另列。（v5 有可增減點位、藥劑引用與不同製作定位方式。）
- [proposed] 查詢資料方式：採版本化本機索引。使用者輸入時立即查本機，詞綴資料更新時才讀取來源。（PoEDB 同一詞義有多階資料，並依類型分頁。設計階段抽查了詞綴索引、All 與戒指分類。）
- [proposed] 多值及讀取失敗：附加傷害等多值詞綴要顯示所比較的數字。模糊搜尋只用於找候選，製作判定依選定的詞綴和來源；辨識不明時暫停製作並指出原因。（火抗、最大火抗、穿透火抗可能同時出現在候選，卻代表不同條件。）
