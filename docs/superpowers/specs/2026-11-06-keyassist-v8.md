# 按鍵輔助 v8 設定檢查與詞綴篩選

## 問題

使用 PoE 1 國際服繁中介面時，需要先知道哪個按鍵、座標或偵測點尚未設定，並能在製作前確認一組詞綴條件是否符合預期。

## 解法

Windows 桌面 App 提供七個頁籤，首頁列出設定完整度，裝備製作頁提供本機詞綴搜尋、四種群組與貼上物品文字的離線比對。

## 實作決策

- 使用 C#、WPF、.NET 10 與 JSON。從同一份草稿衍生紅綠卡片及快捷鍵一覽。
- 偵測點用穩定識別碼引用。校準記錄包含遊戲內容區尺寸及 DPI。座標從內容區左上角起算。
- 詞綴候選按來源與正規化範本聚合，保留來源、資料版本和階級證據。匯入以已取得的本機資料為輸入，搜尋可離線使用。
- 所有啟用群組須通過，範圍包含邊界，空白上下限作存在比對。加權以列值乘權重，與群組分數上下限比較。已確認缺少的詞綴計零，來源或數值不明時顯示無法判定。
- 保存用同目錄暫存檔替換。舊條件原文及失效引用保留供核對。

## 測試決策

- 從設定草稿與首頁導航驗證缺漏、停用、點位刪除、模式切換及保存重開。
- 從搜尋、物品文字及共用規則驗證來源辨識、邊界、四組合成、75 分案例與資料不完整。
- 以 v8 的 A16 至 A21 當作操作驗收依據。合成測試樣本與實際擷取樣本分開記錄。
